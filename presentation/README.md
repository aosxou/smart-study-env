## 🚀 GitHub Pages 배포

### 사전 조건
- Git 저장소 초기화됨
- GitHub 계정 있음

### 배포 단계

1. **모든 파일 커밋**
```bash
git add presentation/
git commit -m "feat: Add presentation slides for EcoMind"
```

2. **GitHub에 푸시**
```bash
git push origin main
```

3. **GitHub Pages 활성화**
   - Repository Settings → Pages
   - Branch: main, Folder: / (root)
   - Save

4. **5분 대기** (배포 완료)

5. **확인**
```
https://<username>.github.io/<repo>/presentation/
```
