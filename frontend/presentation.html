ADR #3: Flask REST API 아키텍처

✓ 이유: 간단하고 빠른 개발
✓ 장점: CORS 지원, 모바일/웹 통합 가능

⚙️개발 환경 & 구현 상세

개발 환경 설정

1. Arduino IDE: 센서 스케치 업로드
2. Python 3.8+ + pip: 백엔드 라이브러리
3. Mosquitto: MQTT 브로커 실행
4. Flask: REST API 서버
5. 웹 브라우저: 프론트엔드 실행

시행착오 & 해결

❌ 초기: 초음파 센서 미응답 → ✅ 제거 후 임시값 사용

❌ 조도 값 역상 표시 → ✅ ADC 변환 공식 수정 ((1023-raw)/1023 적용)

❌ MQTT 데이터 중복 → ✅ 토픽 분리 (microphone vs motion)

❌ 웹캠 CORS 오류 → ✅ localhost에서만 작동하도록 제한

❓Q&A & 활용 방안

예상 질문과 답변

Q1: 빌드와 배포는?

→ 빌드: Flask 자체는 빌드 불필요 (동적 언어)
→ 배포: Docker로 컨테이너화 → 클라우드 배포 가능

Q2: 개인정보 보호는?

→ 웹캠 데이터 localStorage 저장 (서버 미전송)
→ 센서 데이터만 MQTT 전송

Q3: 향후 활용 방안?

→ 모바일 앱 확장 (React Native)
→ 스마트 조명/스피커 제어 통합
