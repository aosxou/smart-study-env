PROBLEM DEFINITION

개발 이유

PROBLEM 01
시간 ≠ 집중
앉은 시간은 재지만,
집중한 시간은 모른다.
PROBLEM 02
원인을 모른다
조도·소음·자세가
집중을 방해해도 알 수 없다.
PROBLEM 03
피드백이 없다
'왜 집중이 안 됐지?'에
답해주는 도구가 없다.
"
센서와 웹캠이 학습 환경을 실시간으로 진단하고, AI가 세션마다 집중을 방해한 원인과 개선 방향을 알려주는 스마트 학습 도우미.

TROUBLESHOOTING

센서 연동 시행착오

1단계 — 초음파 센서
HC-SR04 연동 실패
시도초음파 센서로 착석 여부 및 자세 감지 구현 시도
실패거리 값이 불안정하게 튀어 정확한 자세 판단 불가
결론초음파 센서 제외 결정 → 웹캠 기반 MediaPipe로 대체
2단계 — 조도 센서
조도 센서 미작동
시도조도 센서로 실내 밝기 측정 후 환경 점수 반영 구현 시도
실패센서가 값을 출력하지 않거나 0 고정 — 정상 동작 불가
결론기존 센서 불량으로 판단 → 새 조도 센서로 교체 후 재시도해 정상 작동 확인
3단계 — 웹캠 전환
MediaPipe 집중도 구현
시도초음파 대신 웹캠으로 자세·집중도 측정 재설계
문제고개 숙임 기준값 튜닝 필요 — 처음엔 오탐 발생
결론어깨·귀 키포인트 임계값 반복 조정으로 안정화 성공
