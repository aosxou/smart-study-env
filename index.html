AI가 세션마다 '왜 집중됐는지'를 설명해준다.

PROBLEM DEFINITION

개발 이유

PROBLEM 01
시간 ≠ 집중
앉은 시간은 재지만,
집중한 시간은 모른다.
PROBLEM 02
원인을 모른다
조도·소음·자세가
집중을 방해해도 알 수 없다.
PROBLEM 03
피드백이 없다
'왜 집중이 안 됐지?'에
답해주는 도구가 없다.
